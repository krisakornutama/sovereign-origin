// ส่วนที่ ๔ · ภาษี

จบงวด ภ.พ.30 ก็พร้อมยื่น

ภาษีขายจากทุกออเดอร์ ลบภาษีซื้อจากทุกรายจ่าย (ใส่เลขจากใบกำกับซัพพลายเออร์ได้ในฟอร์มเดียว) — สุทธิขึ้นบนแผ่น ภ.พ.30 เลือกงวดย้อนหลังได้ ครบด้วย ภ.ง.ด.3/50/90 และปฏิทินยื่นนับวันถอยหลัง

  • ภาษีหัก ณ ที่จ่าย ทั้งฝั่งที่เราโดนหัก (เครดิต ภ.ง.ด.50/90) และฝั่งที่เราหัก (ท.ป.4) — จดครบสองฝั่ง
  • ภ.ง.ด.50 นิติบุคคล SME คิดตามทุนจดทะเบียนที่กรอก · ภ.ง.ด.90 บุคคลธรรมดาประมาณการ
  • ปฏิทินยื่น 5 แบบ นับวันถอยหลังอัตโนมัติ — เหลือ ≤14 วันเริ่มเตือน
  • อัตราตามกฎหมายจริง ณ ก.ย. 2569 (VAT 7% ถึง 30 ก.ย. 2569+1ปี แล้วขึ้น 10% เอง)

อยู่รอดด้วยตัวเอง

ระบบเฝ้าตัวเอง กู้ตัวเอง และสำรองข้อมูลทุกวัน — ข้อมูลภาษีของคุณคือหลักฐาน ต้องกู้คืนได้จริง ไม่ใช่แค่ "มี backup ไว้"

🗄️ Backup รายวัน03:00 ทุกวัน

dump ฐานข้อมูลอัตโนมัติทุกวันตีสาม — และซ้อม restore จริง: กู้ลงฐานทดสอบ นับแถวตรงทุกตาราง แล้วจึงเชื่อว่ากู้ได้

🩺 Watchdogเช็คทุก 30 วิ

เดินโปรดหน้าเว็บทุกครึ่งนาที เห็นล้มปลุกกลับมาเองภายในไม่ถึงนาที (ทดสอบจริง: kill เว็บ → ฟื้น < 60 วิ)

🔌 บูตหลังไฟดับauto-start

เปิดเครื่องใหม่ ระบบลุกเองครบทั้งกอง — ไม่ต้องจำว่าต้องกดอะไร

🔐 ความปลอดภัยoffline-first

รหัสผ่านทดสอบที่เคยหลุดเข้า repo ถูกหมุนใหม่แล้ว · ข้อมูลอยู่ในเครื่องคุณ ไม่มีบริการภายนอกอ่าน — ก่อนเปิดสู่อินเทอร์เน็ตจริงต้องมี domain + HTTPS

ตรงไปตรงมา

  • ขายบน Shopee / Lazada ได้คู่กัน — บันทึกยอดขายและค่าธรรมเนียมแพลตฟอร์มเข้าระบบ ตัวเลขภาษีก็ยังครบ
  • AI ต้องติดตั้ง Ollama เองเมื่อพร้อม — ระบบถูกออกแบบให้เดินได้เต็มรูปแบบโดยไม่มี AI

// คำถามที่คนถามจริง

ถาม-ตอบสั้น ๆ

คำถามที่คนแวะมาดูถามบ่อยที่สุด — กดคำถามเพื่อเปิดคำตอบ

ฟรีจริงไหม ต้องจ่ายอะไรอีกไหม

ฟรีทั้งระบบ — ไม่มีค่ารายเดือน ไม่มีค่า cloud เครื่องของคุณคือเซิร์ฟเวอร์ ค่าใช้จ่ายเดียวคือไฟและเน็ตที่จ่ายอยู่แล้ว ถ้าวันหนึ่งอยากขึ้นเว็บสาธารณะ ค่าใหม่เดียวคือ VPS ราวเดือนละหลักร้อย

ผมขายอยู่บน Shopee / Lazada แล้ว ระบบนี้ช่วยอะไร

ใช้คู่กันได้เลย — บันทึกยอดขายและค่าธรรมเนียมแพลตฟอร์มเข้าสมุดบัญชี (ค่าธรรมเนียมมี VAT = ภาษีซื้อ) ระบบแยกภาษีให้เหมือนออเดอร์ในร้าน ตัวเลข ภ.พ.30 ก็ยังครบ

ไฟดับ / เครื่องดับ ข้อมูลจะหายไหม

ไม่หาย — ฐานข้อมูลถูกสำรองทุกวันตีสาม และเคยซ้อมกู้คืนจริงจนนับแถวตรงทุกตาราง เปิดเครื่องใหม่ระบบบูตกลับมาเอง watchdog ปลุกหน้าเว็บถ้าล้ม

ใครมองเห็นข้อมูลของฉันบ้าง

ข้อมูลทั้งหมดอยู่ในเครื่องของคุณ ไม่มีบริการภายนอกอ่าน ลูกค้าบนหน้าร้านเห็นเฉพาะสินค้าที่ขาย — ราคาทุน สต็อก และบัญชีปิดจากหน้าร้านเสมอ

ต้องมีความรู้เรื่องภาษีไหม

ไม่ต้อง — ระบบแยก VAT อัตโนมัติตอนรับเงิน จดภาษีหัก ณ ที่จ่ายทั้งสองฝั่ง ทำปฏิทินยื่นพร้อมนับวันถอยหลัง สิ่งเดียวที่ต้องทำคือกรอกยอดจากใบกำกับซัพพลายเออร์เมื่อมีรายจ่าย

กับร้านอาหารหรือฟาร์มปศุสัตว์ ใช้ได้จริงไหม

ได้ — มีโมดูลเฉพาะทางแล้ว: ร้านอาหารได้เมนู+สูตรคิดทุนต่อจาน จอครัว KDS น้ำหนักครัว/ตู้เย็น IoT และรายงานกำไรรายวัน ส่วนปศุสัตว์ได้ทะเบียนฝูง สุขภาพ+วัคซีน ผลผลิตรายวัน และกำไรต่อรอบการเลี้ยง — และทุกอาชีพใช้บัญชี + ภาษีชุดเดียวกัน

ผมสนใจร่วมพัฒนา/ร่วมมือกับระบบนี้ ต้องเริ่มตรงไหน

ดูหน้า ผลงานทีละชิ้น — แต่ละชิ้นระบุชัดว่ามีอะไรจริงแล้ว กำลังไปทางไหน และต้องการอะไรเพื่อระดับมืออาชีพ เลือกชิ้นที่ถูกใจแล้วเริ่มจากจุดนั้นได้เลย

เดี๋ยวอยากใช้ AI ต้องตั้งค่าเพิ่มไหม

ไม่ต้อง — ระบบตั้งค่าที่อยู่ของ Ollama ไว้ถูกต้องแล้ว พอติดตั้ง Ollama ในเครื่อง ผู้ช่วยทั้ง 5 ตำแหน่งใช้ได้ทันที และช่วงที่ยังไม่มี AI ทุกฟีเจอร์อื่นก็เดินครบ
