  • แต่ละแปลงมีประวัติครบ — วันปลูก วันคาดเก็บเกี่ยว ค่าดิน ปุ๋ยที่ใส่ ผลผลิตที่เก็บได้
  • วิเคราะห์รายแปลง — ต้นทุน/รายได้/กำไรต่อแปลงจากการเก็บเกี่ยวจริง (endpoint analysis)
  • วงจรปุ๋ยปิดสนิท — เศษจากครัวและฟาร์มเข้ากองหมัก แล้วกลับมาเป็นปุ๋ยใส่แปลง ลดต้นทุนจริง
  • แปลงสมุนไพรแยกระบบ — วงสมุนไพรในแปลง ผูกกับฐานข้อมูลสมุนไพรกลาง

// ฐานสมุนไพรไทย · สาธิต

สมุนไพรที่บอกข้อห้ามให้ก่อน

โครงสร้างตรงกับ HerbCatalog ในระบบ: สรรพคุณ ข้อควรระวัง ข้อห้าม จำนวนวันปลูก และดินที่เหมาะ — เลือกชนิดแล้วการ์ดพิมพ์ใหม่ (ข้อมูลสาธิต ไม่ใช่คำแนะนำทางการแพทย์)

  • ปลูกพร้อมรู้วันเก็บ — ทุกชนิดมี growthDays ระบบนับถอยหลังจากวันปลูกในแปลง
  • ดินที่เหมาะตรวจกับค่าดินจริง — ค่า pH/ความชื้นที่ชอบ เทียบกับ soil-readings ของแปลง
  • ข้อห้ามติดไปถึงผู้ใช้ — ใช้คู่กับโมดูลสุขภาพ: เช็คสมุนไพร×ยาที่กินอยู่ก่อนดื่ม/ทาน
  • เก็บแล้วเข้าบัญชี — ผลผลิตสมุนไพรจาก herb-harvest ลงรายได้/สต็อกของบ้านได้

  • เชื่อมสามโดเมน — ครัวร้านอาหาร (เศษอาหาร) + ฟาร์ม + แปลงเกษตร ใช้วงจรนี้ร่วมกัน
  • ทุกกิโลวัดได้ — เข้ากี่ กก. ออกกี่ กก. ใส่แปลงไหน เมื่อไร — audit ได้ทั้งสาย

// ตรงไปตรงมา

ข้อจำกัดที่ควรรู้ก่อนใช้

ตรงไปตรงมา

  • ข้อมูลสมุนไพรในระบบต้องเติมจากแหล่งที่ตรวจสอบแล้ว — โครงสร้าง (สรรพคุณ/ข้อห้าม/วันเก็บ) พร้อม แต่เนื้อหาต้องมาจากตำราที่เชื่อถือได้ ไม่ใช่คำแนะนำทางการแพทย์
  • ค่าดินวันนี้กรอกมือก่อน — โมเดลรับค่าจากเซ็นเซอร์ได้ แต่อุปกรณ์วัดดินจริงยังต้องเพิ่ม
  • ยังไม่มีแปลงนำร่องบันทึกครบรอบ — สูตรกำไรต่อแปลงพร้อม แต่ต้องการการปลูกจริง 1 รอบเพื่อปรับสูตร
