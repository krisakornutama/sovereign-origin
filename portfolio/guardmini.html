// ROI-CENTRIC · ความเสี่ยงที่ป้องกันได้

คิดเป็น "ความเสี่ยงที่ป้องกันได้" ไม่ใช่ "ของแปลกใหม่"

เจ้าของร้านไม่ได้ซื้อกล่อง — ซื้อการนอนตื่นสายโดยไม่ต้องลุกไปเช็คตู้แช่ และไม่เจอวัตถุดิบหลักหมื่นเสียหายเพราะไฟดับตอนตีสาม

1,290–1,490 ฿ ต่อจุด
ราคาขายปลีกต่อกล่อง (ตัวอย่างตลาด) · จ่ายครั้งเดียว ไม่มีค่ารายเดือน
ข้อมูลทั้งหมดอยู่ในร้าน — ไม่มีค่า SaaS แอบแฝง
10,000+ ฿
มูลค่าวัตถุดิบในตู้แช่ร้านอาหารทั่วไป (เนื้อ อาหารทะเล ผัก ของสด) — ทั้งหมดเสี่ยงเสียหายจากไฟดับ/คอมเพรสเซอร์พัง/ปิดประตูไม่สนิทโดยไม่มีใครรู้

ถ้ากล่องช่วยกันเหตุได้แค่ 1 ครั้ง ในอายุหลายปีของมัน ก็คืนทุนแล้ว — ส่วนที่เหลือคือกำไรที่ไม่ต้องเสียไปเลย และการติดตั้งไม่กระทบการขายแม้แต่นาทีเดียว

// ZERO-CONFIG & NON-INVASIVE

ติดตั้งเองได้ใน 3 นาที ไม่เจาะ ไม่ตัดสาย

พนักงานหน้าร้านติดเองได้ — ไม่ต้องรอช่าง ไม่ต้องปิดร้าน ไม่กระทบอุปกรณ์เดิมของร้าน

ขั้นที่ 1 · ~1 นาที

แปะแท่นแม่เหล็ก

แปะกล่องบนแท่นยึดแม่เหล็กนอกตู้ — ไม่ต้องเจาะตู้ ไม่ทิ้งรอย ย้ายตำแหน่งได้ทุกเมื่อ

ขั้นที่ 2 · ~1 นาที

สอดเซนเซอร์เข้าขอบยาง

สายเซนเซอร์แบนพิเศษ สอดเข้าขอบยางประตูตู้ได้ทันที — ไม่ต้องเจาะรู ไม่ต้องแกะฉนวน

ขั้นที่ 3 · ~1 นาที

เชื่อมแจ้งเตือน

เปิดหน้าตั้งค่าจากมือถือ กรอก Telegram/LINE ของร้าน — ทดสอบส่งข้อความ 1 ครั้ง จบ

  • ไม่ตัดต่อสายไฟเดิมของร้าน — ใช้ปลั๊กปกติ ตัดความกังวลเรื่องความปลอดภัยไฟฟ้าและประกันอาคาร
  • ไม่กระทบการขาย — ไม่ต้องปิดร้าน ไม่ต้องขยับตู้ ติดวันนี้ เฝ้าได้ทันที
  • ย้ายได้ — ย้ายกิจการ/เปลี่ยนตู้ ถอนแล้วไปติดร้านใหม่ได้ทันที

// SLA & MODULAR SUPPORT

รับประกัน 1 ปีเต็ม เสีย = เปลี่ยนกล่องใหม่ทันที

ออกแบบให้ซ่อมง่ายและไม่กระทบการทำงานของร้าน — เพราะการรอซ่อมคือความเสี่ยงที่ร้านต้องแบกเอง

เสียเปลี่ยนกล่องใหม่ทันที (Drop-in Replacement)
ในระยะรับประกัน ถ้ากล่องมีปัญหา ส่งกล่องเก่ากลับแล้วใช้กล่องใหม่ต่อได้ทันที — ตั้งค่าใหม่ใน 3 นาที ร้านกลับมาเฝ้าได้ในวันเดียว
ระบุชัดในเงื่อนไข
Modular Support
ตัวเครื่อง แท่นแม่เหล็ก สายเซนเซอร์ เป็นโมดูลแยกกัน — อะไรชำรุดเปลี่ยนเฉพาะชิ้นนั้น ไม่ต้องทิ้งทั้งชุด
ซ่อมบำรุงง่าย
รับประกัน 1 ปีเต็ม

1 ปี

// DATA OWNERSHIP & ZERO SAAS FEE

ข้อมูลยอดขาย สต็อก และการเฝ้าระวัง อยู่ในร้าน 100%

Mini PC ภายในร้านเป็นที่เก็บข้อมูลทั้งหมด — ไม่มี Cloud ข้างนอกอ่าน ไม่มีผู้ขายถือสิทธิ์ข้อมูลแทนคุณ

ข้อมูลอยู่ในเครื่องร้าน 100%
ยอดขาย สต็อก บัญชี และบันทึกอุณหภูมิ เก็บใน Mini PC ภายในร้าน — ไม่มีข้อมูลหลุดออก Cloud ภายนอก
Data Sovereignty
ไม่มีค่าบริการซอฟต์แวร์รายเดือน
ไม่มี subscription ไม่มีค่า cloud ไม่มีค่าเปิดฟีเจอร์ — ค่าใช้จ่ายเดียวคือค่าไฟที่จ่ายอยู่แล้ว
Zero SaaS Fee
สำรองอัตโนมัติ ซ้อมกู้จริง
ระบบหลังบ้านสำรองฐานข้อมูลทุกวันตีสาม และซ้อมกู้คืนจริง — ไฟดับ/เครื่องเสีย ข้อมูลไม่หาย
Backup & Restore
เตือนผ่านช่องทางที่ร้านมีอยู่แล้ว
Telegram/LINE เป็นเพียงช่องทาง "ส่งข้อความ" — ข้อมูลจริงยังอยู่ในร้าน ช่องทางเปลี่ยนได้ทุกเมื่อ
ไม่ผูกมัดแพลตฟอร์ม

// FAILURE MODE HANDLING

เมื่อไฟ/เน็ต/เซ็นเซอร์มีปัญหา — ระบบทำอะไร

ออกแบบเผื่อวันร้าน เพราะเหตุขัดข้องมักเกิดตอนที่มองไม่เห็น — ลองกดจำลองทั้งสามเหตุได้จากแถบเฝ้าระวังข้างบน

🌐

เน็ตหลุด

กล่องเก็บบันทึกอุณหภูมิไว้ใน Memory ชั่วคราว — พอเน็ตกลับมา ยังส่งประวัติที่ขาดหายไปให้ครบ แจ้งเตือนสำคัญเก็บไว้ส่งทีหลัง ไม่หายไปเลย

ผล: ไม่มีช่องว่างข้อมูล
🔌

ไฟดับ

กล่องทำงานต่อด้วยแบตเตอรี่สำรอง และส่งข้อความ "ไฟดับ" เข้า Telegram/LINE ทันทีที่ตรวจพบ — ร้านรู้ตัวก่อนของเสีย

ผล: รู้ตัวภายในนาที
📡

เซ็นเซอร์หลุด/เสีย

ถ้าเซ็นเซอร์เงียบผิดปกติ ระบบส่ง Heartbeat เตือนว่า "มองไม่เห็นตู้แล้ว" — ไม่ปล่อยให้เงียบพร้อมกับความมั่นใจลวง

ผล: ไม่เงียบโดยไม่บอก

// หลักฐานหน้างานจริง — Real-World Evidence

ไม่ใช่แค่โค้ด — ของจริงกำลังถูกสร้าง

ชิ้นงานฮาร์ดแวร์กำลังประกอบทีละชิ้น ส่วนนี้คือบันทึกหน้างานที่ต่อเติมเรื่อย ๆ — รูปตัวเครื่อง คลิปทดสอบเซนเซอร์ และกราฟอุณหภูมิจากการใช้จริง

กำลังโหลดหลักฐาน…

// ตรงไปตรงมา

สถานะจริงของสินค้านี้

ตรงไปตรงมา

  • ระบบเฝ้าระวังฝั่งซอฟต์แวร์มีจริงและรันอยู่ทุกวัน — watchdog เช็คหน้าเว็บทุก 30 วินาที ฟื้นเองเมื่อล้ม (ทดสอบ kill จริง) และแจ้งเตือน Telegram/LINE วิ่งจริงในระบบบ้าน
  • กล่องฮาร์ดแวร์ยังเป็นชิ้นงานกำลังพัฒนา — หน้านี้คือสเปกเป้าหมาย (ราคา แท่นแม่เหล็ก แบตสำรอง) ไม่ใช่สินค้าพร้อมส่งวันนี้
  • ต้องการพาร์ตเนอร์ผลิต/อุปกรณ์ — ร้านที่สนใจทดลองใช้จริง 1 จุด หรือผู้ประกอบการที่อยากร่วมผลิต ติดต่อได้จากหน้า ผู้เขียน
