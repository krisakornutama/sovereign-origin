File seal

Anyone can change a file you sent — but they cannot do it without you finding out. Drop any file (a photo, a video, a PDF, a receipt, a backup, an installer) to get its SHA-256 and a digitally signed seal. Send the file with the seal, and whoever receives it can check that these are the exact bytes you signed, unchanged.

Nothing is uploaded from this machine — it works with no network

    Read this before you rely on a seal for anything that matters
    
      
      
    • A seal only says the bytes did not change and which key signed them — it says nothing about whether the content is true, honest or lawful
      • 
      
    • The time inside a seal is the signer's own claim; no authority attests it
      • 
      
    • To believe a specific person signed it, compare the key fingerprint with a channel you already trust (their main site, their signed email) — not because the file says so
      • 
      
    • The key lives only in this browser; clearing site data or switching machines means importing your backup
