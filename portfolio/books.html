วิธีเติมชั้นหนังสือ

  • เปิดไฟล์ books.html — ขึ้นหัวไฟล์มีบล็อก BOOKS_PUBLISHED กับ BOOKS_READ เขียนด้วย JavaScript ธรรมดา แถวเดียวต่อเล่ม
  • เพิ่มบรรทัดแบบนี้ — { title:'ชื่อหนังสือ', author:'ผู้เขียน', url:'ลิงก์ (ใส่หรือไม่ก็ได้)', note:'คำโปรยสั้น ๆ', category:'กลยุทธ์' } — หมวดใช้ได้ 6 แบบ: กลยุทธ์ · การแพทย์ · สงคราม · การเมืองการปกครอง · ชีวประวัติ · อื่น ๆ (เว้นว่าง = อื่น ๆ) แล้ว push — หน้าเว็บจัดการ์ด + ปุ่มกรองให้เอง
  • ยังว่างอยู่ตอนนี้ = จริง — หน้านี้ไม่แต่งข้อมูลปลอม ชั้นไหนยังไม่ใส่จะขึ้นตัวอักษรว่างตามจริงจนกว่าจะเติม
