# Sovereign OS v1.1.1 — เวอร์ชันแรกที่ตัวติดตั้งมีด่านตรวจ SHA-256 ในตัว

## ความปลอดภัยของการอัปเดต (จากเวอร์ชันนี้เป็นต้นไป)
- **updater ตรวจลายเซ็น SHA-256 ก่อนเปิดติดตั้ง** — อ้างอิงจาก digest ของ GitHub API หรือ `SHA256SUMS.txt` คู่ release · แบบ fail-closed: **ลายเซ็นไม่ตรง / ไม่มีลายเซ็นอ้างอิง / ตรวจไม่ได้ = ลบไฟล์ทิ้ง ไม่เปิดรัน** พร้อมบอกเหตุผลในแอป
- **ดาวน์โหลด settle ทุกเส้นทาง** — ไฟล์เขียนไม่ได้ / HTTP ผิดพลาด = แจ้ง error ทันที ไม่ค้างเงียบ

## ตรวจไฟล์ด้วยตัวเอง
```
certutil -hashfile Sovereign-OS-1.1.1-portable.exe SHA256
```
เทียบกับ `SHA256SUMS.txt` ที่แนบคู่ release — ต้องตรงกันทุกไบต์
