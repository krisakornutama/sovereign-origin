1. **บัญชีปลายทาง** ในสลิปต้องเป็น `4440626505` ชื่อ `กฤษกรณ์ อุตมะ` (ธนาคารกรุงไทย)

## 2. ตอบรับก่อน เพื่อไม่ให้เขาคิดว่าหาย

## 3. ขอข้อมูลสองอย่างจากผู้ซื้อ

- **ชื่อที่จะพิมพ์บนไลเซนส์** (ชื่อบุคคลหรือชื่อร้าน)
- **machine id** จากหน้า `/system` ในแอป (ถ้าเขาให้ไม่ได้ ให้ใช้ `--perpetual` แบบไม่ผูกเครื่องก่อน)

## 4. ออกใบ (คำสั่งเดียว — ออก + ตรวจ + ชุดส่ง + ledger)

รันจากโฟลเดอร์ `sovereign-origin`:

```
node tools/license/sell.mjs --key ../.secrets/license-priv.pem --public-key portfolio/license-pub.txt \
  --licensee "ชื่อผู้ซื้อ" --tier home --machines <machine-id> --days 365 \
  --amount 2140 --sku SW-HOME --paid
```

- `--amount` เป็น **บาท** ไม่ใช่ดอลลาร์: `$59` ใช้เรตวันที่โอน (ซ้อมใช้ `2140`) ตัวเลขนี้คือหลักฐานยอดใน ledger
- `--tier` ต้องตรงกับที่จ่าย: `home` 1 เครื่อง · `business` 3 เครื่อง · `pro` ซื้อขาด (`--perpetual`)
- ยังไม่เห็นเงิน = **ห้ามรัน** เพราะ ledger ต่อท้ายอย่างเดียวและจะถูกจดว่า `paid: false` แก้ทีหลังไม่ได้

## 5. ตรวจซ้ำ (คำสั่งทำให้แล้ว — แต่ต้องอ่านผล)

`sell.mjs` ตรวจใบที่เพิ่งออกด้วยพับลิกคีย์ก่อนเขียนไฟล์ใด ๆ ถ้าไม่ผ่าน มันลบใบและไม่เขียน ledger
⇒ ถ้าเห็น `✗` ให้หยุด แล้วอ่าน error ก่อนออกใบใหม่ **ห้ามส่งใบที่ยังไม่ผ่านให้ผู้ซื้อ**
