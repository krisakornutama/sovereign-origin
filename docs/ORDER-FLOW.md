> เป้าหมาย: เปิดไฟล์เดียว กด Send — ไม่ต้องพิมพ์ไลเซนส์/ใบเสร็จ/อีเมลเอง

## ฝั่งลูกค้า (ไม่ต้องมีใครทำอะไร)

1. เปิด <https://sovereignoriginshop.dpdns.org/order.html>
2. เลือกแพ็กเกจ → หน้าเว็บสร้าง **เลขที่คำสั่งซื้อ** `SO-YYMMDD-XXXX` และยอดโอน (ใช้ `EARLY20` ได้ถึง 5 ธ.ค. 2026)
3. โอนเข้าบัญชีกรุงไทย 4440626505 พร้อมใส่เลขที่ในหมายเหตุ
4. กดปุ่ม "เปิดอีเมลพร้อมรายละเอียด" → ส่งสลิปมาที่ owenhoper3@gmail.com

หน่วยงานที่ต้องใช้ใบเสนอราคา/ใบสั่งซื้อ → <https://sovereignoriginshop.dpdns.org/procurement.html>

## ฝั่งผู้ขาย (คำสั่งเดียว)

```bash
cd sovereign-origin
node tools/order/fulfill.mjs \
  --ref SO-261128-1A2B --tier business \
  --name "ชื่อบนไลเซนส์" --email buyer@example.com \
  --amount 5590 --slip ~/Downloads/slip.jpg
```

ได้ใน `sales/<ref>/`:

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `license.txt` | ไลเซนส์ที่เซ็นแล้ว (ผ่าน sell.mjs ที่ตรวจซ้ำก่อน) |
| `delivery.md` | คู่มือติดตั้ง + public key |
| `receipt.html` | ใบเสร็จรับเงิน (พิมพ์/บันทึก PDF) |
| `email.eml` | อีเมลพร้อมแนบทั้งสามไฟล์ — เปิดแล้วกด Send |
| `order.json` | บันทึกออเดอร์ + รหัสแนะนำ 3 ใบ + sha256 ของสลิป |

`sales/ledger.jsonl` มีแถวของออเดอร์ที่ `paid` แล้ว (ตรวจย้อนได้)

## กติกา

- **ราคาต้องตรง** `pricing.json`: เต็ม 1,990/6,990/20,990 หรือโปร EARLY20 1,590/5,590/16,790 — ถ้าเป็นราคาพิเศษจริงต้องใส่ `--allow-custom-amount`
- **อย่าคัดลอกสลิปเข้า repo** — เครื่องมือเก็บแค่ชื่อไฟล์กับ sha256
- ไลเซนส์ออกไม่ผ่าน = ไม่มีไฟล์ส่ง (fail-closed) ตามดีไซน์ของ `sell.mjs`
- รหัสแนะนำของผู้ซื้อแต่ละคนอยู่ใน `order.json` (`SO-…-R1..R3`, ลด 15% สำหรับการโอนในประเทศ) — เมื่อมีคนใช้ ให้ตรวจว่ามีอยู่ในออเดอร์ไหนก่อนให้ส่วนลด
- คืนเงินภายใน 7 วัน: บันทึกใน `sales/ledger.jsonl` และแจ้งลูกค้าทางอีเมลเดิม

## ตรวจก่อนโพสต์/ก่อนขาย

```bash
npm run pricing:head      # สร้าง head ของ buy.html (meta/og/twitter/JSON-LD) จาก pricing.json — ต้องรันหลังแก้ราคา
npm run pricing:check     # ราคาบนเว็บตรงกับ pricing.json + ไม่มีเลขบัญชีอื่น
npm run check:copy        # คำผิด/คำต้องห้ามทั้งเว็บ
node tools/license/drill.mjs   # ซ้อมออกไลเซนส์ + ตรวจซ้ำ + fail-closed
```
