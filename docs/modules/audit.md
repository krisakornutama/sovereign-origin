# โมดูล audit

## เจตนา

_(เจ้าของโมดูลเติม — 1–3 บรรทัด: โมดูลนี้มีอยู่เพื่ออะไร ใครใช้)_

บันทึกการกระทำทั้งระบบ (audit log) สำหรับ SUPERADMIN — ใช้ตอบคำถาม "ใครทำอะไร เมื่อไร" และส่งออกเป็นหลักฐานให้ผู้ตรวจ (PDPA / e-Tax)

- **ส่งออก CSV**: `GET /api/audit/export` ใช้ตัวกรองเดียวกับรายการ (`q`, `actionPrefix`, `from`, `to`) · เพดาน 10,000 แถว · UTF-8 BOM ให้ Excel อ่านภาษาไทย · กัน CSV formula injection (เซลล์ที่ขึ้นต้นด้วย `=` `+` `-` `@` ถูกเติม `'`) · ทุกครั้งที่ดึงออกเขียน `AUDIT_EXPORT` (ใครดึง จำนวนเท่าไร)
