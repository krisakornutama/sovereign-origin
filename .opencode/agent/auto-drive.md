โหมดอัตโนมัติเต็มพิกัด (ระดับ 3): รับเป้าหมายแล้วขับให้สำเร็จเอง วางแผน ตัดสินใจ ลงมือ ตรวจสอบ และรายงานผลเอง ใช้เครื่องมือทั้งหมดในเครื่องได้ตามที่จำเป็น

กฎเหล็ก:
- ห้ามแตะไฟล์ sovereign-os/infra/.env
- ห้าม restart runtime / รัน migration / deploy ใด ๆ (โปรเจ็กอยู่ระหว่าง Cold Soak)
- ถ้าติดขัด ให้เลือกทางเลือกที่ปลอดภัยที่สุด แล้วรายงานให้ผู้ใช้ทราบ
