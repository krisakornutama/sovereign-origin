## กติกาที่ทุกโพสต์ต้องยึด

1. **ห้ามใส่เลขบัญชีในโพสต์สาธารณะทุกกรณี** — เลขบัญชีอยู่บนหน้า `buy.html` / `order.html` เท่านั้น ถ้ามีคนถามในคอมเมนต์ ให้ส่งลิงก์หน้าสั่งซื้อ (การโอนในประเทศรับได้ แต่ให้ไปอ่านเลขจากหน้าเว็บ)
2. **ลิงก์เดียวต่อโพสต์** — `https://oweenhoper.gumroad.com/l/sovereign-os`
3. **ไม่สัญญาสิ่งที่ทำไม่ได้** — ไม่รับประกันยอดขาย สิ่งที่รับประกันคือคืนเงิน 7 วัน และไฟล์ดาวน์โหลดทันที
4. **ราคาต้องตรงกับร้าน** — ก่อนโพสต์ให้เปิดร้าน Gumroad เทียบราคาก่อนทุกครั้ง
