## เมื่อมีคนโอนเงิน (ขั้นที่ทำให้ "เงินเข้ากระเป๋า" จริง)

1. ตรวจสลิป: ชื่อบัญชีผู้โอน ยอด และเวลา ให้ตรงกับที่ตกลง (บัญชีรับเงินอยู่บนหน้า buy เท่านั้น)
2. ออกไลเซนส์และชุดส่งลูกค้าด้วยคำสั่งเดียว:
   `npm run license:sell -- --key <private.pem> --public-key <public.pem> --licensee "ชื่อร้าน" --tier business --machines <machine-id> --days 365 --amount 4900 --sku SW-BUSINESS --paid`
3. ส่งไฟล์ใน `sales/<order>/` (`license.txt` + `delivery.md`) ให้ผู้ซื้อ และเก็บแถวใน `sales/ledger.jsonl` ไว้นับยอด
4. ถ้าติดตั้งไม่สำเร็จภายใน 7 วัน คืนเงินเต็มจำนวนตามที่ประกาศไว้

## ตรวจความสอดคล้องก่อนโพสต์ (30 วินาที)

รันจากโฟลเดอร์ `sovereign-origin`:

```
node portfolio/scripts/check-copy.mjs
grep -o "1,490\|4,900\|14,900" portfolio/buy.html | sort -u
grep -o "1,490\|4,900\|14,900" marketing/*.md | sort | uniq -c
grep -c "sovereignoriginshop.dpdns.org/buy.html" portfolio/buy.html marketing/*.md
```

ผลที่ต้องเห็น: check-copy ขึ้น PASS · ราคาทั้งสามค่าโผล่ทั้งหน้า buy และไฟล์การตลาด · ลิงก์ buy.html มีในทุกไฟล์โพสต์
