- ตัวเลข $47.20 / $159.20 / $479.20 บนหน้าเว็บ **ไม่ต้องพิมพ์เอง** — `promo.js` คำนวณจาก `pricing.json` ให้ (ดูหัวข้อถัดไป)

## ขั้นตอนในหลังร้าน (Checkout → Discounts)

> Gumroad ปี 2026 ย้ายโค้ดส่วนลดไปหน้าเดียวระดับบัญชี: **Checkout → Discounts** (ไม่ใช่ในหน้าสินค้า)

1. เข้า <https://gumroad.com/> → เมนูซ้าย **Checkout** → แท็บ **Discounts**
2. กด **New discount**
3. **Code**: พิมพ์ `EARLY20` (ตัวพิมพ์ใหญ่ ไม่มีช่องว่าง — Gumroad รับเฉพาะตัวอักษรกับตัวเลข)
4. **Products**: เลือกเฉพาะสินค้า **Sovereign OS — self-hosted operations suite (one-time license)**
   (อย่าเลือก “All products” — บัญชีนี้มีสินค้าอื่นเช่น Sovereign Seal ที่แจกฟรี)
5. **Discount type**: `Percentage` → ใส่ **20**
6. **Limit quantity**: ใส่ **50** (เป็นการจำกัดจำนวนครั้งรวมทั้งบัญชี ไม่ใช่ต่อคน — อย่าประกาศว่า “คนละ 1 ครั้ง”)
7. **Expiry**: ตั้งวันสิ้นสุด **5 ธ.ค. 2026 เวลา 23:59 (เวลาไทย)** — ตรงกับ `pricing.json` → `promo.expires`
   (ถ้าช่องเวลาเป็น UTC ให้ใส่ `2026-12-05 16:59` = 23:59 น. เวลาไทย)
8. **Save** — หลังบันทึก Gumroad จะให้ลิงก์สินค้าที่ต่อท้ายด้วยโค้ด:
   `https://oweenhoper.gumroad.com/l/sovereign-os/EARLY20`
9. **ยังไม่ต้องเปิด** “Automatically apply discount code” ในหน้าสินค้า — เปิดเฉพาะช่วงที่จะลดทั้งร้าน เพราะมันทำให้ราคาที่ทุกคนเห็นลดทันทีโดยไม่ต้องมีโค้ด (กดเปิดได้ทีหลังถ้าต้องการ)

2. ตรวจว่าหน้าร้านขึ้น **$47.20** (Home) และเมื่อเปลี่ยนเป็น Business/Pro ขึ้น **$159.20 / $479.20**
3. ใส่โค้ดที่ช่อง checkout ด้วยมืออีกรอบ → ต้องได้ราคาเดียวกัน (ไม่ซ้อนกัน)

6. จดผลลงท้ายไฟล์นี้: วันที่ตรวจ + ราคาที่เห็นทั้งสามแพ็กเกจ

## เปิดให้หน้าเว็บโชว์โปรบัตร — แก้ที่เดียว

หน้าเว็บผูกกับ `pricing.json` แล้ว (`portfolio/promo.js` อ่านค่าให้ทั้ง `order.html` และ `buy.html`)
ไม่ต้องแก้ข้อความในหน้าเว็บเลย:

1. เปิด `portfolio/pricing.json` → ในบล็อก `promo`
2. เปลี่ยน `"gumroadUrl": null` เป็น

```json
"gumroadUrl": "https://oweenhoper.gumroad.com/l/sovereign-os/EARLY20",
"channel": "bank-transfer + gumroad",
```

3. รันชุดตรวจ (จะฟ้องถ้า URL ไม่ตรงกับสินค้า/โค้ด หรือลิงก์ถูก hardcode ไว้ในหน้าเว็บ):

```bash
cd sovereign-origin
npm run pricing:check      # รวมข้อบังคับของ promo.gumroadUrl ↔ หน้าเว็บ
npm run check:copy
cd portfolio && node scripts/audit.js   # ต้อง AUDIT CLEAN
```

4. commit + push → workflow `Deploy portfolio` ขึ้นเว็บให้เอง แล้วยิง IndexNow ต่อ

**ผลลัพธ์บนหน้าเว็บเมื่อใส่ `gumroadUrl` แล้ว** (ข้อความสร้างจาก JSON อัตโนมัติ):

- `order.html` → ป้ายโปร: `ใช้โค้ด EARLY20 (ลด 20% — ใช้ได้ทั้งการโอนในประเทศและการจ่ายบัตรที่ Gumroad ถึง 5 ธ.ค. 2026)` · โน้ตท้ายการ์ดเป็นลิงก์ `หน้าร้าน Gumroad — $47.20` · ปุ่ม “จ่ายด้วยบัตร” ชี้ลิงก์ที่มีโค้ด
- `buy.html` → ข้อความใต้การ์ดแพ็กเกจ: `โค้ด EARLY20 ลด 20%: Home $47.20 · Business $159.20 · Pro $479.20 (ถึง 5 ธ.ค. 2026) — ใช้ได้ทั้งบัตรที่ Gumroad และการโอนเข้าบัญชีด้านล่าง`
- ถ้า `gumroadUrl` ยังเป็น `null` (หรือเปิดเว็บแบบไม่มี JS) หน้าเว็บคงข้อความเดิม = “ลด 20% สำหรับการโอนในประเทศ” — ไม่โฆษณาส่วนลดบัตรที่ยังใช้ไม่ได้
