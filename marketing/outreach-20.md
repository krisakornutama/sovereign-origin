## 2. หาเบอร์/อีเมลเอง (ไม่เดา ไม่ซื้อลิสต์)

- **Google Maps**: `<ประเภท> <อำเภอ/จังหวัด>` → ดูเบอร์โทร/เว็บไซต์ในหน้า place (ช่องทางที่ถูกที่สุด)
- **Facebook Page**: ค้น `<ชื่อร้าน> สอบถาม` → ใช้ปุ่ม "ส่งข้อความ" ไม่ใช่คอมเมนต์สาธารณะ
- **เว็บไซต์ร้าน**: หน้า "ติดต่อเรา" — เลือกอีเมลจริง ไม่ใช้ `noreply@`
- **ห้าม** ใช้อีเมลที่เดาขึ้นเอง, ห้ามซื้อลิสต์, ห้ามยิงอัตโนมัติ

กรอกลงตารางข้อ 5 ทีละแถวก่อนส่ง — ถ้าไม่มีชื่อจริง/ช่องทางจริง ให้ข้ามแถวนั้น

## 3. ข้อความ 3 ฉบับ (คัดลอกได้เลย)

### 3.1 อีเมล — ร้านค้า/คลินิก (ไทย)

หัวเรื่อง: `ระบบหลังบ้านที่รันบนเครื่องคุณเอง — ใช้ตอนเน็ตหลุดก็ได้`

```
สวัสดีครับ คุณ{{ชื่อ}},

ผมกฤษกรณ์ พัฒนา Sovereign OS — ระบบหลังบ้านที่ติดตั้งบนคอมพิวเตอร์ Windows เครื่องเดียวของร้าน
ไม่ต้องเช่าเซิร์ฟเวอร์ และใช้งานต่อได้แม้เน็ตหลุด

สิ่งที่เกี่ยวกับร้านโดยตรง:
- สต็อกสินค้า + ใบเสร็จ + VAT 7%
- แดชบอร์ดยอดขาย/ค่าไฟ ย้อนหลังเป็นกราฟ
- สำรองข้อมูลแบบเข้ารหัส และกู้คืนได้
- สิทธิ์ผู้ใช้แยกตามบทบาท (เจ้าของ/พนักงาน)

ราคาจ่ายครั้งเดียว $59 (Home, 1 เครื่อง, อัปเดต 1 ปี) ไม่มีรายเดือน
ดูรายละเอียดและภาพหน้าจอจริงได้ที่ https://sovereignoriginshop.dpdns.org/buy.html
มีการรับประกันคืนเงินเต็มจำนวนภายใน 7 วันถ้ารันบนเครื่องคุณไม่ได้

ถ้าสนใจ ผมส่งคำตอบสั้น ๆ 3 ข้อ (ใช้กี่เครื่อง/ข้อมูลอยู่ที่ไหน/ติดตั้งยากไหม) ให้ก่อนได้ครับ
ตอบกลับอีเมลนี้ได้เลย

กฤษกรณ์ อุตมะ
```

### 3.2 DM — โรงงาน/ฟาร์ม (สั้นกว่า ไทย)

```
สวัสดีครับ ผมกฤษกรณ์ นักพัฒนาระบบ Sovereign OS
สนใจเรื่องการเฝ้าระบบ (เซนเซอร์/เครื่องจักร) แบบที่ข้อมูลอยู่บนเครื่องคุณเองไหมครับ
ตัวระบบรับค่าจากเซนเซอร์ผ่าน MQTT, แจ้งเตือนเข้า Telegram/LINE และเก็บประวัติย้อนหลังได้
ติดตั้งบน Windows เครื่องเดียว จ่ายครั้งเดียว $59 ไม่มีรายเดือน
รายละเอียด: https://sovereignoriginshop.dpdns.org/buy.html
ถ้าสะดวก ผมขออนุญาตส่งคลิป 15 วินาทีที่ระบบรันจริงให้ดูครับ
```

### 3.3 ติดตามครั้งเดียว (หลัง 4 วัน ไม่มีการตอบ)

```
สวัสดีครับ ขออนุญาตติดตามข้อความก่อนหน้าครับ
ถ้ายังไม่เหมาะกับร้านตอนนี้ ไม่เป็นไรครับ — ผมขออนุญาตถามสั้น ๆ ข้อเดียว:
ระบบที่คุณใช้อยู่ตอนนี้ติดอะไรที่สุด (ราคา/ข้อมูลต้องออกเน็ต/ใช้งานยาก)? ผมเอาไปปรับสินค้าให้ตรงขึ้นครับ
```
> ตอบกลับข้อความใด ๆ = หยุดขายทันที ตอบคำถามตรง ๆ แล้วปิดท้ายด้วยลิงก์ครั้งเดียว
