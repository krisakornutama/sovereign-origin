# Fastwork — กิกพร้อมลง (ค่าบริการติดตั้ง + ไลเซนส์รวมในราคา)

**ทำไมต้องรวมไลเซนส์ในราคา:** Fastwork ห้ามพาลูกค้าออกไปจ่ายนอกแพลตฟอร์ม (ห้ามวางลิงก์/ไลน์/เบอร์ในแชท)
ถ้าแยกให้ลูกค้าไปซื้อเองจะผิดกฎและเสียงาน — จึงตั้งราคาเป็น "ค่าบริการติดตั้ง + ไลเซนส์" แล้วผมเป็นคนซื้อไลเซนส์
ให้ลูกค้าผ่านร้านของผมเอง (ต้นทุน $59/$199/$599 หักจากราคาที่รับมาแล้ว)

## ชื่อกิก

```
ติดตั้งระบบหลังบ้านร้านค้า (ขาย–สต็อก–ใบกำกับ–VAT) พร้อมใช้ใน 3 วัน
```

## คำอธิบายกิก

```
รับติดตั้งและตั้งค่าระบบหลังบ้านสำหรับร้านค้า ร้านอาหาร หรือกิจการครอบครัว ให้พร้อมใช้งานจริงในเครื่องของคุณเอง
ไม่ต้องจ่ายรายเดือน และใช้งานต่อได้แม้เน็ตหลุด

ผมเป็นผู้เขียนระบบนี้เอง จึงตั้งค่าได้ถึงชั้นข้อมูล (สินค้า สต็อก ใบกำกับ ภาษี) ไม่ใช่แค่ติดตั้งโปรแกรมแล้วส่งงาน

เหมาะกับ
- ร้านที่ต้องออกใบกำกับและส่งข้อมูลให้นักบัญชีทุกเดือน
- กิจการที่ต้องการข้อมูลอยู่ในเครื่องตัวเอง ไม่ขึ้นคลาวด์
- ร้านที่ใช้หลายเครื่อง (หน้าร้าน + หลังบ้าน)

สิ่งที่ทำได้หลังติดตั้ง
- ขายหน้าร้าน/POS รับ PromptPay QR พร้อม VAT 7%
- ตัดสต็อก ออกใบกำกับ ลงสมุดเงินสด และออกรายงานส่งนักบัญชี
- แดชบอร์ดยอดขายย้อนหลัง มอนิเตอร์พลังงาน เซนเซอร์แจ้งเตือน
- แบ็อปเข้ารหัส และทำงานต่อได้ตอนเน็ตหลุด (ค่อยซิงก์เมื่อกลับมา)
- ผู้ช่วย AI ที่อ่านเฉพาะข้อมูลในเครื่องคุณ

ไม่รวมในราคา: ออกแบบโลโก้/แบรนด์, พัฒนาฟีเจอร์ใหม่เฉพาะกิจ, ย้ายข้อมูลจากระบบเก่าที่ไม่มีไฟล์ส่งออก
(ส่วนนี้ประเมินราคาแยกได้)
```

## กฎที่ต้องถือในแชท Fastwork

- **ห้ามวางลิงก์ภายนอก / LINE / เบอร์โทร / เลขบัญชี** — ผิดกฎแพลตฟอร์มและอาจถูกระงับบัญชี
- ถ้าลูกค้าถามว่าโปรแกรมนี้มาจากไหน: `เป็นซอฟต์แวร์ที่ผมพัฒนาขึ้นเองครับ ขายเป็นไลเซนส์ ฉันเป็นคนดูแลระบบให้ต่อ`
- ถ้าลูกค้าถามราคาเดียวทั้งระบบ: เสนอ "มาตรฐาน 8,900 บาท" ก่อน แล้วค่อยประเมินงานนอกเหนือ
- ถ้าลูกค้าต้องการซื้อโปรแกรมอย่างเดียวไม่เอาบริการ: บอกว่าผมขายผ่านร้านออนไลน์ของผม และ **ไม่ต้องส่งลิงก์ในแชท**
  (ถ้าลูกค้าถามชื่อร้านเองจึงค่อยบอกชื่อ ไม่ใช่ลิงก์)

## FAQ 5 ข้อ (ก๊อปตอบได้)

1. **ต้องใช้คอมแบบไหน** — Windows 10 หรือ 11 ขึ้นไป, แรม 8 GB ขึ้นไป, ใช้ไฟล์ portable ไม่ต้องติดตั้งเพิ่ม
2. **ต้องต่อเน็ตตลอดไหม** — ไม่ต้อง ระบบทำงานในเครื่อง ไลเซนส์ตรวจแบบออฟไลน์
3. **ข้อมูลอยู่ที่ใคร** — อยู่ในเครื่องคุณ ผมไม่มีสิทธิ์เข้าถึง และไม่เก็บสำเนา
4. **เปลี่ยนเครื่องได้ไหม** — ได้ แจ้งมาออกไลเซนส์ใหม่ให้ ปีละ 1 ครั้งไม่คิดเงิน
5. **ขอใบกำกับภาษีได้ไหม** — ตอนนี้ยังไม่จดทะเบียน VAT จึงออกได้เฉพาะใบเสร็จรับเงิน

1. ออกไลเซนส์ให้ลูกค้าด้วยคำสั่งเดียว:
   ```bash
   npm run license:sell -- --key <private.pem> --public-key <public.pem> --licensee "ชื่อร้าน" --tier home --machines <machine-id> --days 365 --amount 3900 --sku FW-INSTALL-HOME --paid
   ```
   (นี่คือคำสั่งในเครื่องของคุณ ไม่ใช่ข้อความโพสต์ — แทนค่า `<...>` ด้วยไฟล์/ข้อมูลจริงตอนรัน)
2. ส่งไฟล์ `license.txt` ให้ลูกค้าทางแชท Fastwork (ไม่ต้องส่งลิงก์นอก)
3. เก็บหลักฐานการโอนจาก Fastwork ไว้คู่กับเลขงาน เผื่อลูกค้าถามภายหลัง
