=== หมวดคู่มือและการดูแลระบบ Sovereign OS ===

[การอ่านค่าเซ็นเซอร์ดินและความชื้น]
1. ตรวจสอบค่า Soil Moisture จากหน้า Dashboard
2. หากความชื้นต่ำกว่า 20% ระบบจะแนะนำให้เปิดรดน้ำ
3. หากค่า EC สูงกว่าปกติ AI จะแจ้งเตือนเพื่อสุ่มตรวจดินเค็ม

[การตรวจสอบสถานะประตูและระบบความปลอดภัย]
1. ตรวจสอบ door_state บน Dashboard (Open / Closed)
2. หากประตูเปิดค้างไว้เกิน 15 นาที ในช่วงกลางคืน ระบบจะแจ้งเตือน
3. สามารถตรวจสอบกล้องหรือเซ็นเซอร์การเคลื่อนไหวเพิ่มเติมได้

[การกู้คืนระบบเมื่อเซ็นเซอร์หรือเครือข่ายหลุด]
1. ตรวจสอบสถานะ EMQX Broker และพอร์ต MQTT (1883)
2. รีสตาร์ทบริการ Core-API ด้วยคำสั่ง npm run dev
3. ตรวจสอบไฟสถานะ LED บนบอร์ด ESP32 ว่าเชื่อมต่อ Wi-Fi/LoRa อยู่หรือไม่
