# แก๊สชีวภาพ (Biogas) 1m³ จากเศษอาหาร 10kg

ถังหมัก 1m³ ใส่เศษอาหาร 10kg + น้ำ 10ลิตร + หัวเชื้อ 1kg ปิดสนิท 30 วัน ได้แก๊ส 1m³ (หุงต้ม 2ชม.) + กาก 8kg เป็นปุ๋ย. เหมาะกับร้านอาหารเศษเยอะ. ต่อยอดจาก compost: กากจาก biogas → ปุ๋ยหมักต่อ. ต้องมีถังแก๊สและวาล์วนิรภัย. แท็ก: biogas, compost, waste, energy, s4
