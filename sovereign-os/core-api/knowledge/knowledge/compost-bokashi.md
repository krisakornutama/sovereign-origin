# โบกาฉิ (Bokashi) — หมักเศษอาหารรวมเนื้อสัตว์

รำข้าว 5kg + กากน้ำตาล 1kg + EM 1ลิตร + น้ำ 10ลิตร หมัก 7 วัน ได้หัวเชื้อ. เศษอาหารทุกชนิด (รวมเนื้อสัตว์) 10kg + หัวเชื้อ 1kg คลุกในถังปิดสนิท 14 วัน ได้ปุ๋ยหมักกรด ฝังดิน 7 วันก่อนปลูก. เหมาะกับ plate_waste จากร้านอาหารที่มีเนื้อสัตว์. แท็ก: compost, bokashi, waste, s4
