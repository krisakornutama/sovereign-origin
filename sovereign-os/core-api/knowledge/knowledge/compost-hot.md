# ปุ๋ยหมักแบบร้อน (Hot Compost) — C:N 25-30:1, 14-21 วัน

เศษอาหาร 10kg + ใบไม้แห้ง 5kg + ปุ๋ยคอก 2kg คลุกให้ C:N ~25-30:1 ความชื้น 50-60% (กำแล้วเป็นก้อนไม่แตก). กองสูง 1ม. กลับกองทุก 3 วัน อุณหภูมิกลางกอง 55-65°C ฆ่าเชื้อ. เสร็จใน 14-21 วัน ได้ปุ๋ย 5kg (สูญเสีย 50%). ใช้ 2kg/ตรม. ใส่แปลงก่อนปลูก 7 วัน. เหมาะกับเศษผักผลไม้จากครัวร้านอาหาร. แท็ก: compost, fertilizer, waste, s4, ปุ๋ยหมัก
