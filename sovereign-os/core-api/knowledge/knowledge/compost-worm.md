# ไส้เดือนดิน (Vermicompost) — ปุ๋ยมูลไส้เดือน

กระบะ 1x2ม. ใส่เบดดิ้ง (ขุยมะพร้าว+มูลวัว 1:1) หนา 15ซม. ปล่อยไส้เดือน AF 1kg กินเศษอาหาร 0.5kg/วัน เก็บมูลทุก 30 วัน ได้ปุ๋ย 10kg/เดือน N-P-K สูง + จุลินทรีย์. ใช้ 1kg/ตรม. ใส่แปลงสมุนไพร (บัวบก, ขมิ้น). ห้ามใส่ของมัน/เปรี้ยวจัด. แท็ก: compost, worm, waste, s4
