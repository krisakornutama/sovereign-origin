=== หมวดแผนฉุกเฉิน และการรับมือภัยพิบัติ ===

[แผนฉุกเฉินไฟไหม้]
1. เปิดสัญญาณเตือนภัยทันทีเมื่อพบกลุ่มควันหรือความร้อนผิดปกติ
2. รวมพลที่จุดนัดพบหน้าบ้านหรือจุดปลอดภัยเหนือลม
3. ใช้ถังดับเพลิงประเภท ABC หากเพลิงยังไม่ลุกลามมาก
4. ตัดเมนคัทเอาท์ไฟฟ้า และติดต่อวิทยุสื่อสารฉุกเฉิน

[แผนฉุกเฉินน้ำท่วม]
1. ขนของ อุปกรณ์อิเล็กทรอนิกส์ และคลังอาหารขึ้นที่สูง
2. ตัดระบบไฟฟ้าแรงดันสูงทั้งหมด เหลือไว้เฉพาะไฟฉุกเฉิน 12V/24V
3. เปิดปั๊มน้ำฉุกเฉินเพื่อสูบน้ำออกจากอาคารหลัก
4. อพยพไปยังจุดปลอดภัยที่กำหนดไว้หากระดับน้ำยังเพิ่มสูงขึ้น

[การเตรียมกระเป๋าฉุกเฉิน Bug Out Bag]
1. อาหารแห้งและน้ำดื่มสำหรับอย่างน้อย 3 วัน
2. ชุดปฐมพยาบาล ยาประจำตัว และยาฆ่าเชื้อ
3. วิทยุ FM/AM, ไฟฉาย, แบตเตอรี่สำรอง
4. มีดพก, จุดไฟเช็ค, และเอกสารสำคัญในซองกันน้ำ
