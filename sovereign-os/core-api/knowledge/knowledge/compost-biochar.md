# ไบโอชาร์ (Biochar) — ถ่านชีวภาพปรับดิน

เผาแกลบ/ไม้ไผ่ แบบไร้อากาศ 400-500°C 4ชม. ได้ถ่านพรุน 1kg/วัตถุดิบ 3kg. แช่น้ำหมักจุลินทรีย์ 24ชม. ก่อนใช้. ใส่ 0.5kg/ตรม. คลุกดินลึก 15ซม. คงอยู่ 100 ปี เพิ่ม CEC อุ้มน้ำ ลด EC. ใช้กับดินกรด/ดินทรายของสมุนไพร (ฟ้าทะลายโจร, ขมิ้น). แท็ก: biochar, compost, fertilizer, s4
