# Agent Runner — ตัวรันงานบนคอมแต่ละเครื่อง

Runner เป็นตัวรันงานที่ทำงานอยู่บนเครื่องคอม (รวมเครื่องนี้ด้วย) เพื่อ:
1. ส่ง heartbeat ไปบอก HUB ว่า "ฉันออนไลน์"
2. ดึงงานจาก HUB ที่คิวไว้
3. สั่ง agent ทำงาน (opencode CLI เป็นต้น)
4. ส่งผลลัพธ์กลับ HUB ให้แจ้งเตือนทาง Telegram

## ทำไมต้องเป็นแบบ "ดึงงาน" (pull) ไม่ใช่ HUF ยิงมาหา

- เครื่องคอม **ไม่ต้องเปิดพอร์ต** รับ จึงไม่ต้องแก้ firewall
- HUB ไม่ต้องมี public URL — ทุกอย่างอยู่ใน LAN
- ถ้าเครื่องคอมปิด งานจะรออยู่ในคิว ไม่หาย เปิดมาแล้วทำต่อ

## ติดตั้ง (ทำครั้งเดียวต่อเครื่อง)

**1) เอา token จาก HUB**
เปิดหน้าเว็บของ HUB → หัวข้อ "เครื่องสั่งงาน" → กด **ลงทะเบียนเครื่องใหม่**
ระบบจะคืน token ครั้งเดียว (คัดลอกเก็บไว้เลย ดูซ้ำไม่ได้)

**2) เตรียมไฟล์ตั้งค่า**
```bash
cp .env.example .env
# แก้ .env: ใส่ HUB_URL (IP ของโน้ตบุ๊คใน LAN) และ MACHINE_TOKEN
#   HUB_URL ต้องเป็น http://<IP-ของโน้ตบุ๊ค>:3000 เท่านั้น (ห้ามใช้ :3001 —
#   API ผูกกับ 127.0.0.1:3001 เครื่องใน LAN ต่อตรงไม่ติด ต้องผ่านหน้าเว็บ :3000 ที่ rewrite /api/* ให้)
```

**3) ทดสอบก่อน — ยังไม่ต้องติดตั้งถาวร**
```bash
node src/main.mjs
```
ต้องเห็น `เครื่อง=... hub=... executor=...` แล้วไม่ขึ้น error

**4) ติดตั้งให้รันอัตโนมัติ (Windows)**
คลิกขวา `install-runner.cmd` → **Run as administrator**
จะสร้าง Scheduled Task ชื่อ `Sovereign Agent Runner` ให้รันทุกครั้งที่ล็อกอิน

## executor ที่รองรับ

| executor | สถานะ | หมายเหตุ |
|---|---|---|
| `echo` | ใช้ได้เลย | ทดสอบสายตรง ไม่ต้องพึ่ง agent จริง |
| `opencode` | ใช้ได้ | ต้องติดตั้ง `opencode-ai` (npm) — `npm i -g opencode-ai` |
| `freebuff` | ยังไม่ได้ | Freebuff เป็น desktop app ไม่มี headless CLI — runner จะรายงานว่าทำไม่ได้ (ไม่เงียบ) |

## โมเดลเลือกเองได้

`opencode` จะใช้โมเดลที่กำหนดไว้ใน `opencode.json` หรือค่าเริ่มต้นของเครื่อง
ถ้าอยากบังคับโมเดลต่องาน ให้ส่ง `executor_model` มากับงาน (เช่น `ollama/gemma3`)

## อัปเดตโค้ดตัวเองจาก HUB (ไม่ต้องก็อปไฟล์ผ่าน USB อีก)

หลังแก้โค้ดที่โปรเจ็ก HUB แล้วรัน `node tools/agent-pack/pack.mjs` (หรือแค่ `publishUpdateBundle`)
เครื่องลูกจะได้รับเวอร์ชันใหม่เองในรอบตรวจถัดไป (ค่าเริ่มต้น: ตรวจครั้งแรกหลังเริ่ม 30 วิ แล้วทุก 6 ชม.)

**เวอร์ชันคืออะไร:** sha256 ของ (ชื่อไฟล์ + hash เนื้อหา) ของทุกไฟล์ในชุด เรียงชื่อ
คำนวณจากเนื้อไฟล์จริง **ทั้งสองฝั่งใช้สูตรเดียวกัน** (`src/selfUpdate.mjs` — ตัวแพ็ก import โมดูลนี้)
⇒ ไม่มีไฟล์เก็บเวอร์ชันให้เพี้ยน และไม่ต้องมีคนคอยอัปเดตเลขเวอร์ชัน

**ขั้นตอนในเครื่องลูก:**
1. `GET /api/agent-machines/update/manifest` (header `x-machine-token`) → ได้รายการไฟล์ + hash
2. เทียบกับเวอร์ชันที่คำนวณจากไฟล์ในเครื่อง — ตรงกันแล้วจบ (ไม่ดาวน์โหลดอะไร)
3. ดาวน์โหลดทุกไฟล์ลงโฟลเดอร์พัก → ตรวจ sha256 ให้ครบ → ตรวจไวยากรณ์ (`node --check`)
4. เก็บสำเนาของเดิมที่ `.runner-backup/<เวอร์ชันเดิม>/` → สลับไฟล์ → เขียน state ค้าง
5. ปล่อยโปรเซสใหม่ (detached) แล้วเฝ้า: ประกาศตัว = ส่งงานต่อ (exit 86) · ไม่ประกาศ = **ย้อนกลับเวอร์ชันเดิมเอง**
   + จำเวอร์ชันนั้นไว้ 24 ชม. กันอัปเดตวนซ้ำกับโค้ดที่พัง

**คำสั่งตรวจด้วยมือ** (รันในโฟลเดอร์ runner):
```bash
node src/main.mjs --print-version     # เวอร์ชันโค้ดที่เครื่องนี้กำลังรัน
node src/main.mjs --check-update      # HUB มีเวอร์ชันใหม่ไหม (ไม่แตะไฟล์)
node src/main.mjs --self-update       # เช็ค+ติดตั้ง+รีสตาร์ท เดี๋ยวนี้
```
ปิดการอัปเดตอัตโนมัติได้ที่เครื่องนี้: `SELF_UPDATE=false` หรือ `--no-self-update`

**ตัวห่อ `run-runner.cmd`:** รัน runner ให้ฟื้นเองเมื่อ crash และรับช่วงตอนอัปเดต (exit 86)
ตัวติดตั้งตั้ง scheduled task ให้เรียกไฟล์นี้อยู่แล้ว — เครื่องที่ตั้งไว้ก่อนหน้านี้ (task เรียก `node src\\main.mjs` ตรง ๆ)
ยังอัปเดตได้ปกติ แต่จะไม่ฟื้นเองเมื่อ crash

**ความปลอดภัย:** route อัปเดตต้องมี token ของเครื่องเท่านั้น และให้บริการเฉพาะไฟล์ที่อยู่ใน manifest
(ไฟล์บนดิสก์ถูกแก้หลังเผยแพร่ = ปฏิเสธ ไม่ส่งออก) · ชื่อไฟล์ที่มี `..`/absolute ถูกปฏิเสธ · `.env`/`join.json` ไม่อยู่ในชุด

## ทดสอบด้วยมือ
```bash
npm test                   # เทสต์ทั้งหมด (ไม่ต้องต่อ HUB)
```

> เทสต์ `test/selfUpdateHub.test.mjs` คุยกับ HUB จริง — ถ้า HUB ไม่ได้รันหรือยังไม่เผยแพร่ชุดอัปเดตจะข้ามเอง (ไม่แดง)
> ต้องมี `HUB_URL` + `MACHINE_TOKEN` ใน `.env` ของโฟลเดอร์นี้

> `node --test test/` (แบบเก่าในเอกสาร) ใช้กับ Node รุ่นใหม่ไม่ได้ — จะได้ `tests 1 / fail 1`
> ให้ใช้ `npm test` ซึ่งขยายเป็น `node --test test/*.test.mjs` ให้เอง
